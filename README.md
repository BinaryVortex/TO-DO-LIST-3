# TO-DO-LIST-3

A simple, elegant to-do list web application built with HTML, CSS, and JavaScript.

## Features

- Add new tasks by typing and pressing Enter or clicking the + button
- Mark tasks as completed or pending with checkboxes
- Filter tasks by status (completed/incomplete)
- Delete individual tasks using the × button
- Delete all tasks at once with the "Delete All" button
- Data persistence using browser localStorage
- Responsive design with a modern, blurred UI and beautiful background

## Technologies Used

- HTML5
- CSS3 (with backdrop-filter for blur effects)
- JavaScript (ES6+)

## How to Run

1. Clone or download the repository
2. Open `index.html` in any modern web browser
3. Start managing your tasks!

No server required - it's a client-side application.
